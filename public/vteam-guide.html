5. 상세 설정 · 관리

회사 운영 설정은 관리자가, 개인 설정은 누구나 변경할 수 있습니다. 화면 언어는 한국어와 영어만 지원하며, 채팅·태스크 내용은 자동 번역됩니다. 초대 이메일 자동 발송과 회사별 시간대 설정은 준비 중이며, 모든 기능은 완전 무료로 제공합니다.

(1) 설정 메뉴
메뉴내용권한
멤버초대, 역할 변경, 퇴사 처리관리자
회사 정보회사명·로고·사업자번호·주소관리자
근무 규정고정/시차/자율 근무, 코어타임관리자
연차 제도자동 부여·이월·근속 가산관리자
출퇴근 IP 제한허용 IP(CIDR) 등록관리자
계정모국어 / 화면 언어(한·영)모두
(2) 처음 세팅 체크리스트 (관리자)
  1. 회사 만들고 → 근무 규정 먼저 설정
  2. 연차 제도 설정 (자동 부여 켜기)
  3. 필요하면 출퇴근 IP 등록
  4. 멤버 초대 (가입할 구글 이메일 직접 안내)
  5. 첫 프로젝트 생성 → 메인/서브 태스크로 분배
  6. 팀에 이 설명서 공유 🎉
