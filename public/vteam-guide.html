Getting Started

1. 시작하기

구글 계정으로 로그인합니다. 회사를 새로 만들거나 초대를 받아 합류할 수 있습니다. 다만 초대 이메일은 아직 자동 발송되지 않으므로, 관리자가 가입을 직접 안내해 주세요.

🏢 회사를 처음 만드는 경우

  1. 구글로 로그인
  2. 회사 이름 + 내 이름 입력
  3. 만든 사람이 자동 관리자
  4. 설정 → 멤버에서 팀원 초대

🙋 초대를 받는 경우

  1. 관리자가 내 구글 이메일로 초대 등록
  2. 그 이메일로 구글 로그인 → 회사 자동 인식
  3. 이름·직책·입사일·모국어 입력

5. 상세 설정 · 관리

회사 운영 설정은 관리자가, 개인 설정은 누구나 변경할 수 있습니다. 화면 언어는 한국어와 영어만 지원하며, 채팅·태스크 내용은 자동 번역됩니다. 초대 이메일 자동 발송과 회사별 시간대 설정은 준비 중이며, 모든 기능은 완전 무료로 제공합니다.

(1) 설정 메뉴

메뉴내용권한
멤버초대, 역할 변경(관리자↔직원), 퇴사 처리관리자
회사 정보회사명·로고·사업자번호·주소관리자
근무 규정고정/시차/자율 근무, 필수시간, 코어타임관리자
연차 제도자동 부여·이월·근속 가산관리자
출퇴근 IP 제한허용 IP(CIDR) 등록관리자
조직도보고 라인 설정관리자
계정모국어 / 화면 언어(한·영)모두

(2) 처음 세팅 체크리스트 (관리자)

  1. 회사 만들고 → 근무 규정 먼저 설정
  2. 연차 제도 설정 (자동 부여 켜기)
  3. 필요하면 출퇴근 IP 등록
  4. 멤버 초대 (가입할 구글 이메일 직접 안내)
  5. 첫 프로젝트 생성 → 메인/서브 태스크로 분배
  6. 팀에 이 설명서 공유 🎉

팀 전체가 같은 화면을 보게 만드세요

출퇴근부터 프로젝트·휴가·소통까지 한 곳에서. 언어가 달라도 자동 번역으로 막힘없이 일합니다.
