Getting Started

1. 시작하기

구글 계정으로 로그인합니다. 회사를 새로 만드는 사람과, 초대를 받아 합류하는 사람 두 흐름이 있어요.

🏢 회사를 처음 만드는 경우

  1. 구글로 로그인
  2. 회사 이름 + 내 이름 입력
  3. 만든 사람이 자동 관리자
  4. 설정 → 멤버에서 팀원 초대

🙋 초대를 받는 경우

  1. 관리자가 내 구글 이메일로 초대 등록
  2. 그 이메일로 구글 로그인 → 회사 자동 인식
  3. 이름·직책·입사일·모국어 입력
⚠️ 현재 초대 이메일은 자동 발송되지 않습니다. 관리자가 "이 메일로 가입하세요"라고 직접 안내해 주세요.
🔒 다른 회사 사람은 초대 없이는 우리 워크스페이스에 못 들어옵니다. 회사별 데이터가 완전히 분리돼요.

9. 도입 시 관리자 체크리스트

  1. 회사 만들고 → 근무 규정 먼저 설정
  2. 연차 제도 설정 (자동 부여 켜기)
  3. 필요하면 출퇴근 IP 등록
  4. 멤버 초대 (가입할 구글 이메일 직접 안내)
  5. 첫 프로젝트 생성 → 메인/서브 태스크로 일감 나누기
  6. 팀에 이 설명서 공유 🎉
📌 정식 상용 도입 전 준비 중: 결제·구독(현재 무료) · 초대 이메일 자동 발송 · 회사별 시간대 설정
